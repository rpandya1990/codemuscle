# 0004: Persist deterministic daily queues and recommendation reasons

## Status

Accepted

## Decision

Daily queues are generated by an explicit scoring policy with centralized weights and duration
defaults. Candidates are sorted deterministically, severe overdue or failed items retain priority,
and remaining capacity prefers topic diversity. A greedy selector never exceeds the available-time
budget.

Queue sessions and items are persisted. Every item stores the score, estimated duration, and
human-readable reasons used when it was selected. Remove and postpone operations change item status
instead of deleting history. A postponed item receives a visible one-day manual date override.

## Consequences

- A historical queue does not change when problem statistics change later.
- Queue generation remains explainable and testable without AI.
- Equal-score candidates use title and UUID as stable tie-breakers.
- The greedy fit may leave unused minutes when no remaining problem fits; this is preferable to
  exceeding the requested session duration.
